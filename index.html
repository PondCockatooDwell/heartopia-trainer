Features

Everything you need, one overlay

Six core modules built for Heartopia — each toggled instantly from the in-game menu with zero restarts.

👁️

Memory ESP

Reads entity positions straight from memory to draw player boxes, health bars, and distance labels through any wall.

🧱

Wallhack

See enemies, loot, and objectives behind geometry with adjustable render distance and color-coded visibility states.

🎯

Aimbot

Smooth or instant target snapping with configurable FOV, bone priority, and humanized smoothing to keep it natural.

🌀

Teleport

Jump to saved waypoints, waypoints on the map, or any entity position with a single hotkey — no walking required.

⚡

Speed Hack

Multiplier-based movement control from 1.2x to 10x with a toggle key, so you move at the pace you choose.
